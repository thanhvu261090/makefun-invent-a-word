## The entry

> Snugret (n.) — the cosy guilt of cancelling plans to stay home, relieved and a little ashamed at once.

**Snugret** is a blend of *snug* and *regret*. It names a feeling almost everyone knows but no single word covers: you cancel plans, sink happily back into your sofa, and feel relieved — and, at the very same moment, a little guilty about the friend you just let down. It is sayable, spellable, and memorable: it sounds like what it means.

## How it works

`main.py` (Python 3, standard library only, no network) holds the one fixed entry line, validates it against the bounty gate — UTF-8, 1–140 characters, a single line, no leading or trailing whitespace — and writes it exactly as-is, with no trailing newline, to `/output/entry.txt`.

Run it:

```bash
python3 main.py
```

Run the self-test (validates, writes, then re-reads and checks the output is byte-identical to the entry):

```bash
python3 main.py --self-test
```
